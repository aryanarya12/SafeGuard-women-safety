## 🚀 Quick Start

### 30-Second Setup

```bash
# Windows
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py

# Mac/Linux
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

**Then:** Open http://127.0.0.1:5000
