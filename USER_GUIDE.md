# SafeGuard User Guide - v2.0

## Welcome to SafeGuard!

SafeGuard is a comprehensive women safety application designed to help you stay safe in urban areas. This guide will help you understand and use all its features.

---

## 🎯 Quick Start

### Step 1: Access the Application
1. Open your browser
2. Go to `http://localhost:5000`
3. You should see the SafeGuard homepage

### Step 2: Explore Features
Click on any feature in the navigation menu:
- **Home** - Overview and introduction
- **Features** - Learn about all capabilities
- **Dashboard** - Access safety tools
- **About** - Understand our mission
- **Contact** - Get help and support

## 📍 Main Features

### 1. **Crime Mapping Dashboard**

**What it does:**
- Shows crime hotspots on an interactive map
- Color-coded by risk level
- Displays incident counts

**How to use:**
1. Scroll to Dashboard section
2. View the map with crime hotspots
   - 🔴 Red = High risk
   - 🟠 Orange = Medium risk
   - 🟢 Green = Low risk

**Tips:**
- Hover over hotspots for more information
- Zoom in/out to see different areas
- Check this before planning your route

### 2. **Get My Location** 📍

**What it does:**
- Retrieves your current location
- Shows distance from crime hotspots
- Updates real-time speed

**How to use:**
1. Click "Get My Location" button
2. Allow location access when prompted
3. Your position appears on the map
4. View nearby incidents count

**Privacy Note:**
- Location data is only used while using the app
- Your location is not stored or shared
- Can be disabled anytime

### 3. **Find Safe Route** 🛤️

**What it does:**
- Calculates the safest route to your destination
- Avoids high-crime areas
- Shows estimated travel time
- Displays CCTV coverage

**How to use:**
1. Enter your destination in the text field
2. Click "Calculate" button
3. Review the suggested route:
   - Distance in km
   - Estimated time
   - Risk level
   - CCTV coverage
   - Nearby emergency services

**Route Factors:**
- Crime statistics
- Street lighting
- CCTV availability
- Emergency service proximity

### 4. **CCTV Monitoring** 📹

**What it does:**
- Activates real-time CCTV monitoring
- Uses facial recognition to detect threats
- Provides live feed monitoring

**How to use:**
1. Click "Start CCTV Monitoring" button
2. Status shows "CCTV monitoring active"
3. System monitors for suspicious activity

**What it monitors:**
- 127+ public cameras
- Real-time threat detection
- Facial recognition enabled
- Automatic alerts if threats detected

### 5. **Emergency SOS** 🚨

**IMPORTANT: Only use in genuine emergencies!**

**What it does:**
- Sends immediate emergency alert
- Notifies authorities and emergency contacts
- Shares your location
- Alerts nearby SafeGuard users

**How to use:**
1. Click the red "Emergency SOS" button
2. Confirmation dialog appears
3. Click "Confirm SOS" to send alert
4. Alert sent to:
   - Police
   - Emergency contacts
   - Nearby SafeGuard users
   - Local authorities

**Important:**
- Only click if you're in genuine danger
- Response time: < 2 minutes
- Cannot be undone
- Multiple confirmations prevent accidental clicks

### 6. **Status Indicators** 📊

The dashboard displays real-time information:

| Indicator | Meaning |
|-----------|---------|
| ✅ Safe | No threats detected nearby |
| ⚠️ Warning | Crime zones within 2km |
| 🚨 Danger | Immediate threat detected |
| 📍 Location | Your current position |
| 📊 Speed | Current movement speed |
| 🆘 Incidents | Number of nearby incidents |

## ❓ FAQ

### Q: Is this app free?
**A:** Yes! SafeGuard is free for all women. No premium features.

### Q: Does it require mobile data?
**A:** Recommended but works on WiFi too. GPS may work even without data.

### Q: Can others see my location?
**A:** No, unless you explicitly share for emergency SOS.

### Q: What if I accidentally click SOS?
**A:** You'll get a confirmation dialog. Only confirmed clicks send alerts.

### Q: Does it work offline?
**A:** Partially. Map may not load, but location still works.

### Q: How accurate is the location?
**A:** Within 5-10 meters usually. Depends on GPS signal.

### Q: Can I use this at night?
**A:** Yes! App has nighttime mode. Maps show better in darkness.

### Q: What's the response time for SOS?
**A:** Average response < 2 minutes. Varies by area.

### Q: Is my data safe?
**A:** Yes. All data encrypted. No personal data stored.

### Q: Can I contact support?
**A:** Yes! Email: support@safeguard.com or call 1098.

## 🐛 Troubleshooting

### Issue: App won't load
**Solution:**
1. Refresh browser (F5)
2. Clear cache (Ctrl+Shift+Delete)
3. Try different browser
4. Check internet connection

### Issue: Location not working
**Solution:**
1. Allow location permission
2. Check GPS is enabled
3. Wait a few seconds for GPS lock
4. Try getting location again

### Issue: Map not loading
**Solution:**
1. Check internet connection
2. Refresh page
3. Zoom out on map
4. Try different browser

### Issue: SOS not working
**Solution:**
1. Check internet connection
2. Wait for confirmation dialog
3. Ensure you clicked "Confirm SOS"
4. Try again after 10 seconds

### Issue: Route calculation fails
**Solution:**
1. Check destination spelling
2. Ensure you're on the map
3. Try a different destination
4. Check internet connection

### Issue: Speed not updating
**Solution:**
1. Enable high-accuracy location
2. Move the device
3. Wait for GPS lock
4. Check GPS is enabled
